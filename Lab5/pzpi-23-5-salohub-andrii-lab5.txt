3 ОПИС ВИКОНАНОЇ РОБОТИ

     Проєкт CarHistory є єдиною централізованою інформаційною платформою, що створена для забезпечення повної прозорості та безпеки на вторинному ринку автомобілів (зокрема в Україні та країнах ЄС).  
     Головна ідея проєкту - надати покупцям і власникам транспортних засобів швидкий та зручний інструмент для перевірки реального минулого й поточного стану автомобіля за його VIN-кодом.
      Система покликана захистити покупців від найпоширеніших видів шахрайства на авторинку, таких як:  
• штучне скручування пробігу;   
• приховування наслідків серйозних ДТП;  
• приховування фактів затоплення машини.

     Для забезпечення високої продуктивності, строгої типізації та можливості подальшого масштабування було обрано такий технологічний стек:  
- Серверна частина: Node.js, Express, TypeScript, Bun, PostgreSQL, Drizzle ORM, Swagger, ESP32 (IoT).  
- Клієнтська частина: React, TypeScript, shadcn/ui, TanStack Router, Zustand, React Query, i18next.  
- Мобільний застосунок: iOS, Swift, SwiftUI (архітектурний патерн MVVM, URLSession).  
- Розгортання та інфраструктура: Платформа Fly.io (для хостингу бекенду), хмарна реляційна база даних Neon (PostgreSQL).

     В результаті розробки було успішно запущено мінімально життєздатний продукт , який включає:  
- REST API Моноліт: Повноцінний клієнт-серверний REST API на базі Bun/Express із автоматичним розгортанням інфраструктури на Fly.io.  

- Хмарне сховище: Надійне хмарне сховище даних на базі реляційної БД PostgreSQL (у третій нормальній формі).  
- Інтелектуальні алгоритми бізнес-логіки:   
• Інтелектуальна система перевірки скручування пробігу;   
• Автоматичний розрахунок індексу ризику автомобіля;   
• Динамічна генерація текстових рекомендацій для користувача.   
- Веб-інтерфейс: Повністю двомовний веб-інтерфейс для водіїв, інтерактивна документація Swagger для розробників, а також адмін-панель для модерації даних та адміністрування бази даних.  
- Мобільний додаток: Нативний мобільний додаток для iOS.  
- IoT-модуль: Робочий прототип апаратного модуля на базі мікроконтролера ESP32 для зчитування даних автомобіля. Реалізовано алгоритм згладжування апаратних шумів датчиків та динамічну синхронізацію конфігурацій з сервером.  

     Через юридичні, фінансові та технічні обмеження на початковому етапі розробки до наступних спринтів було відтерміновано такі фічі:  
- Офіційні інтеграції: Інтеграція з державними реєстрами МВС України та міжнародними базами даних для автоматичного підтягування історії володіння та ДТП.  
- Платіжний шлюз: Повноцінне підключення платіжного сервісу для монетизації та купівлі розширених звітів, через що наразі весь функціонал працює в безкоштовному тестовому режимі.  
- Push-сповіщення: Система push-повідомлень у мобільному додатку для миттєвого інформування водія про критичний стан автомобіля (наприклад, затоплення салону чи критичне падіння заряду акумулятора), коли додаток згорнутий.  



4 ВИСНОВКИ
     Назва інструменту та версія: Gemini 3.1 Pro.
     Мета використання: сформувати базовий формат висновку до лабораторної роботи.
     Внесок автора: проаналізував згенерований текст, вніс деякі зміни в написаний варіант і довів його докінцевого вигляду.
     Розробка екосистеми CarHistory завершилася успішним запуском мінімально життєздатного продукту. Завдяки використанню сучасної хмарної інфраструктури (Fly.io, Neon), строго типізованого коду (TypeScript, Swift) та проектування реляційної бази даних у третій нормальній формі, створена система демонструє високий потенціал для подальшого горизонтального та вертикального масштабування під будь-які обсяги навантаження. 
      Попри те, що деякі складні зовнішні інтеграції та фінансові модулі було перенесено на наступні етапи розробки, успішна комбінація веб-версії, нативного iOS-додатка та робочого IoT-прототипу на базі ESP32 повністю підтверджує працездатність обраної архітектури та відкриває широкі можливості для розвитку проєкту на авторинку України та ЄС.
